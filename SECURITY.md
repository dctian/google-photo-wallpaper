# Security and privacy

The dedicated browser profile contains a signed-in Google session. Anyone who
can read it may be able to use that session. Do not share it, export cookies,
include it in support archives, or upload it to CI.

The application reads selected albums and downloads wallpaper copies. It does
not upload photos to an analysis service. A photo-download allowance limits
activity; it is not a guarantee of Google approval or account safety.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository when available.
Do not post authentication tokens, private photo URLs, account details, or
personal pictures in a public issue. Public bug reports should contain only
synthetic or thoroughly redacted examples.

Only the latest release receives fixes. This early release has not undergone
an independent security audit. Undocumented endpoint compatibility and expired
Google sessions may require maintenance or manual sign-in.
